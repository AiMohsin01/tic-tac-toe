# 🎮 AIM ARCADE — Tic Tac Toe

Welcome to **AIM ARCADE**, a modern browser version of the classic Tic Tac Toe game. It combines a blue arcade-inspired interface with smooth gameplay, a smart CPU challenger, and a simple way to play with friends on the same device.

![Made with HTML, CSS and JavaScript](https://img.shields.io/badge/Made%20with-HTML%2C%20CSS%20%26%20JavaScript-1677d2?style=for-the-badge)

## ✨ Features

- **Solo mode** — play as X against the built-in CPU opponent.
- **Local multiplayer** — two players can play on the same screen.
- **Player profiles** — enter player names before a match; names are remembered after refresh.
- **Smart CPU moves** — the computer wins when it can, blocks immediate wins, and prioritizes strong squares.
- **Scoreboard and round tracker** — keep track of every round in the current match.
- **Winner celebration** — a congratulation popup appears when a player wins.
- **Responsive design** — works well on desktop and mobile screens.

## 🚀 Play the game

1. Download or clone this project.
2. Open `index.html` in a modern web browser.
3. Enter your name, choose a game mode, and start playing.

No installation, backend, or build command is needed.
